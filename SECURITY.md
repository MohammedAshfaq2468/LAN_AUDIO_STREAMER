# Security policy

This is an in-development portfolio project, not a security-audited release.

Please do not report vulnerabilities by publishing exploit details in an issue. Contact the maintainer privately using the contact details shared outside this repository.

Before public releases, review network discovery, UDP input validation, local firewall guidance, Android exported components/permissions, dependency versions, and Windows process/system-control permissions. Never commit API tokens, passwords, keystores, signing keys, private device logs, or machine-specific configuration.
