# Android client source snapshot

The `source-snapshot/src/main` tree contains the Kotlin, native C++, CMake, and selected XML layout files that were available in the workspace.

Package: `com.example.wifiaudiospeaker`

The original Android project root, Gradle wrapper/build scripts, manifest, and complete resource tree were not supplied. This folder is therefore a source snapshot for review, not a directly importable Android Studio project.

The `experiments/custom-adaptive-v1` folder is an isolated candidate. It contains full replacement files and a new `CustomBufferEngine.kt`. It is not part of the baseline snapshot and is not device-validated. Review its README and static checks before integrating it.
